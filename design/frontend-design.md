# TubeInsight 前端设计方案

> 版本 v1.0 · 面向实现（可直接转换为 React + Tailwind / CSS 变量）
> 产品：海外 YouTube 内容洞察 AI Agent（AI 内容军师）

---

## 0. 一句话定位

给"海外内容运营"用的 **AI 数据分析 Agent 界面**：对话是主入口、数据看板是辅助、内容军师工作流是批量工具。视觉走深色 AI 工具风（参照 Linear / Vercel / Notion AI），用 **YouTube 红** 作为品牌色、**紫罗兰** 作为 AI 能力标识色，双色语言贯穿全站。

---

## 1. 设计原则（每条都能在面试里讲）

1. **对话优先**：用户不用学图表，直接说人话——"对比这两个频道的互动率"就能拿到结果。
2. **数据一眼可读**：每个指标卡片自带环比变化（↑↓）和 3 秒内能说清的含义；图表默认只展示一个核心对比，避免信息过载。
3. **AI 过程透明**：Agent 每次 Tool Calling 的"思考 → 选工具 → 传参 → 结果"全程可视化，用户能看到 AI 在干什么、为什么这么干——这是建立信任的关键，也是和普通"问一句答一句"聊天框拉开差距的地方。
4. **每屏都有下一步**：任何页面都提供一个"接下来该干嘛"的 CTA（生成选题 / 跑工作流 / 问视频内容），引导用户深入使用。
5. **面向海外业务，中英双语**：UI 文案全部走 i18n，默认中文、可一键切英文，体现"海外内容业务"属性。

## 2. 设计系统（Design Tokens）

### 2.1 色彩

- 🔴 **品牌红** `#FF3B30` —— 一切与 YouTube / 内容数据 / 主操作相关；

### 2.2 字体

- 字体栈：`"Inter", -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 等宽（代码 / 日志 / JSON）：`"JetBrains Mono", "SF Mono", "Cascadia Code", Consolas, monospace`
- 基准字号 14px，行高 1.6（中文排版舒适）

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| display | 28/36 | 600 | 页面大标题（工作台问候语） |
| h1 | 22/30 | 600 | 页面标题 |
| h2 | 18/26 | 600 | 区块标题（卡片组） |
| title | 15/22 | 600 | 卡片标题 / 列表项标题 |
| body | 14/22 | 400 | 正文 |
| secondary | 13/20 | 400 | 辅助信息 |
| caption | 12/18 | 400 | 时间戳 / 元信息 |
| mono | 13/20 | 400 | 代码 / 参数 / 日志 |

### 2.3 间距 / 圆角 / 阴影 / 动效

- **间距**：4px 基准网格：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`
  - 页面左右内边距 24，卡片内边距 20，卡片间距 16，区块间距 24。
- **圆角**：按钮/输入框 6，卡片 8，聊天气泡 10，标签/徽标 999。
- **阴影（仅用于浮层，卡片一律用描边区分）**：
  - `shadow-pop`：`0 4px 16px rgba(0,0,0,.35)`（下拉 / 弹窗，暗色下翻倍到 `.5`）
- **动效**：hover 150ms ease；面板展开/收起 250ms ease；AI 流式输出光标 700ms 呼吸闪烁。

**关键交互（本页是全站亮点）**：
1. **Tool Calling 可视化**：AI 消息内的工具调用卡片按 ①思考 → ②选工具 → ③调用 → ④完成 四步展示，参数 JSON 可展开/折叠，结果摘要带复制按钮。右侧面板同步显示时间线（含耗时，如"2.4s"）。
2. **流式输出**：文字逐字出现，末尾有呼吸光标；输出完成后光标消失。
3. **@引用**：输入框支持 `@频道/视频` 快速挂载上下文，形成右侧"会话上下文"chips。
4. **引用来源**：AI 回答里出现的数据点，用小标签链接到具体频道/视频页（如 `[频道 MrBeast]`）。
5. **建议下一步**：AI 每次回答后，右侧面板根据意图动态给出 1~2 个快捷 CTA（一键生成发布建议 / 图表 / 跑工作流）。

### 4.5 内容军师 Workflow（`/workflow`）

**目标**：一键跑通"选题 → 竞品对比 → 标题 → 脚本 → 发布建议"全流程。

```
┌──────────────────────────────────────────────────────────────┐
│ ⚡ 内容军师 · 配置输入                                          │
│ [频道选择 ▾] [主题/方向: AI 工具测评] [目标: 涨粉] [⚡ 开始运行]    │
├──────────────────────────────────────────────────────────────┤
│ 流水线（5 步，实时状态）                                         │
│ ① 选题分析  ✓   ② 竞品对比  ✓   ③ 标题生成  ⟳ 运行中…  ④ 脚本… ⑤ 发布… │
│  ────●────────●────────●────────○────────○───                 │
├──────────────────────────────────────────────────────────────┤
│ 结果区（按步骤纵向排列产出卡片）                                    │
│ ┌─ ① 选题分析 ──────────────────────────────────────────┐      │
│ │ 3 个选题方向，每个含热度趋势 + 竞争度 + 理由（附引用）          │      │
│ │ [📋 复制] [📥 导出]                                      │      │
│ └───────────────────────────────────────────────────────┘      │
│ ┌─ ③ 标题生成 ─ 10 个标题，A/B 标签 ────────────────────────┐     │
│ └───────────────────────────────────────────────────────┘      │
│                                                                 │
│ 历史运行（右侧或底部列表：主题 / 状态 / 耗时 / 重新运行）              │
└────────────────────────────────────────────────────────────────┘
```

**关键交互**：
- 步骤条实时反映运行状态：`等待 ○ → 运行中 ⟳(旋转) → 完成 ✓ / 失败 ✗`，失败步骤可点开看错误日志（等宽字体）；
- 每步产出独立卡片、可复制/导出；运行中允许用户"跳过当前步骤"；
- 全部完成弹出汇总 Toast + 一键导出 Markdown 报告。

## 6. 关键交互与三态规范

- **三态**（每页每个区块都必须有）：
  - 空态：无数据时的引导（导入频道 / 新建会话 / 首次运行工作流）；
  - 加载态：骨架屏或区块级 spinner，禁止白屏；
  - 错误态：错误卡片 + "重试"按钮 + 可复制错误信息。
- **Tool Calling 透明度**：所有工具调用默认展示摘要，可展开参数；右侧时间线记录耗时——面试演示时直接展示"AI 思考→调用→完成"全过程。
- **流式输出**：文字逐字渲染 + 呼吸光标，完成后立即渲染 Markdown 表格/图表。
- **复制与导出**：一切 AI 产出（标题、脚本、报告）均可一键复制；工作流支持导出 Markdown。
- **i18n**：文案键值表，默认 zh-CN，可切 en；**日期数字用海外格式习惯**（`May 12, 2025`）。

## 8. 面试讲解点（怎么用这份设计讲故事）

1. **"我参考了 Linear / Vercel / Notion 的 AI 产品设计语言"**——克制配色、描边代替阴影、深色为主，体现审美与眼界。
2. **"双色语义系统"**——红=内容数据、紫=AI 能力，用户 1 秒区分"这是数据还是 AI 在干活"。
3. **"我把透明性当核心卖点"**——Tool Calling 四步可视化 + 耗时记录 + 参数可展开，这是 AI Agent 类产品建立信任的标准做法，说明我理解 Agent 产品的本质不只是聊天。
4. **"数据密度与可读性平衡"**——指标卡永远带环比与一句话说明，图表默认单一对比，避免海外内容运营同事看不懂。
5. **"全站 i18n + 海外格式"**——呼应公司"海外内容业务"，说明我有产品思维。
6. **落地**：这份设计直接对应 React 组件树（`Sidebar/Topbar/StatCard/ChatBubble/ToolCallCard/Stepper…`），Tailwind 或 CSS 变量都能 1:1 实现。
