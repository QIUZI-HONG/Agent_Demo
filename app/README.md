# TubeInsight · 可运行版（设计稿美化 + 流程跑通）

## 怎么运行
直接双击打开 `app/index.html` 即可。**无需安装任何东西、无需联网**（浏览器打开）。

## 界面结构（按设计稿美化，5 个页面）
| 页面 | 功能 |
|---|---|
| 工作台 | 统计卡片 + 最近分析记录（点击跳频道洞察）+ 最近工作流 |
| Agent 对话 | 输入频道名 → 展示 Tool Calling 时间线（①解析→②选工具→③调用→④结论）+ 工具调用卡片（参数 JSON 可展开）+ 分析结论 + 来源引用 |
| 频道洞察 | 频道数据卡 + 趋势图 + AI 内容理解（RAG 主题分布）+ 视频列表 + AI 结论 |
| 内容军师 | 配置（频道/主题/目标）→ 5 步流水线动画 → 选题 / 标题 / 发布建议产出 |
| 设置 | 模型、YouTube/LLM Key、MCP 状态、主题/语言、清空数据 |

右侧顶栏可切换暗色/亮色主题、切换模型。

## 演示数据 vs 真实数据
- **默认**：内置演示数据，完整跑通流程（不需要任何 Key）。
- **接真实数据（可选）**：设置页填：
  - `YouTube Data API Key`：https://console.cloud.google.com 启用 YouTube Data API v3 后创建。
  - `LLM API Key`（可选）：如 DeepSeek 开放平台 key，填了之后 AI 结论由真实大模型生成。
  - Key 只保存在浏览器 localStorage，不上传任何服务器。
- 没填 Key / Key 无效 / 网络失败 → 自动回退演示数据并提示，流程不断。
